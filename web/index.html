How to use:
1. Enter a unique request ID (for example R019).
2. Choose a shop and urgency from 1 to 5.
3. Add one or more commodities and quantities in kilograms.
4. Submit, then open Requests to process the queue.

Allocation uses urgency ranking, stock availability, vehicle capacity and the shortest road route.
